# Upload availability

Click Upload CSV on the availability site, choose one Ski School Summary CSV, and click Commit changes directly to main. GitHub sign-in is required; no token is needed.

The Publish availability action validates both disciplines and updates the shared calendar automatically. Allow a few minutes for deployment. If validation fails, the last successfully deployed calendar remains live. Upload one CSV per commit. Files in this public repository are public; upload only the Ski School Summary counts export.
